게임에서 직접 삭제 — 버전 0.7.1부터

메일을 보내지 않아도 직접 처리할 수 있습니다. 게임의 설정 → 개인정보 · 계정 → 계정과 저장 데이터 → 클라우드 계정 · 기록 삭제를 선택하세요. 삭제 내용을 확인하고 본인 확인 후 영구 삭제를 누른 뒤 게임에 연결한 것과 같은 Google 계정을 선택합니다. 인터넷 연결이 필요합니다.

삭제 대상은 이 게임의 Firebase 로그인 계정과 클라우드에 백업한 진행도·진행 중인 퍼즐·별·인테리어·단골손님 기록입니다. 복구할 수 없습니다. Google 계정 자체, 다른 게임의 계정, 이 휴대폰 및 다른 기기의 저장 사본은 삭제하지 않습니다.

클라우드 기록 삭제와 로그인 계정 삭제는 순서대로 처리됩니다. 통신 오류나 계정 삭제 실패 시 완료로 표시하지 않으며 자동 백업을 중지합니다. ‘계정 삭제 마무리 필요’ 또는 ‘삭제 결과 확인 필요’가 표시되면 같은 계정으로 다시 확인하세요. 게임 기록은 서버에서 제거되며, 예전 기기의 재업로드를 막기 위해 기존 게임 사용자 식별자와 삭제 시각만 담은 최소한의 삭제 표식은 유지합니다. 서비스 제공업체의 보안 로그 등에는 해당 업체의 보유 정책이 적용될 수 있습니다.

기기 기록은 별도로 삭제합니다

클라우드와 기기 기록은 서로 별개입니다. 한쪽을 삭제해도 다른 쪽은 남습니다.

  1. 남겨 둘 기록이 있다면 먼저 백업합니다.
  2. 게임을 완전히 닫고 Android 설정을 엽니다.
  3. 앱(애플리케이션) → 우당탕 초밥집 → 저장공간 → 데이터 삭제를 선택합니다. 기기에 따라 ‘저장용량 비우기’로 표시됩니다.

이 작업은 이 휴대폰에 저장된 모든 계정·게스트의 진행, 설정 및 로그인 상태를 지웁니다. 되돌릴 수 없습니다. ‘캐시 삭제’만으로는 진행 기록이 지워지지 않습니다. 클라우드 계정과 백업은 지워지지 않으므로 다시 연결하면 복원될 수 있습니다. 다른 기기의 로컬 기록은 각 기기에서 별도로 삭제해야 합니다.

로그아웃과 재연결

설정 → 개인정보 · 계정 → Google 로그아웃은 삭제가 아닙니다. 기기 사본과 클라우드 백업은 유지됩니다. 클라우드 계정을 삭제한 뒤 다시 Google 백업을 연결하면 새 게임 계정이 만들어지고 남아 있는 기기 기록이 다시 업로드될 수 있습니다.

게임에 접근할 수 없는 경우

구버전을 이용 중이거나 앱을 열 수 없다면 게임에 연결한 이메일로 evolvekorea@gmail.com에 ‘우당탕 초밥집 계정 삭제’를 요청할 수 있습니다. 정상적인 앱 내 삭제에는 이메일이 필요하지 않습니다. 비밀번호나 인증 코드는 보내지 마세요.

Account and data deletion — Sushi Scramble

Sushi Scramble (우당탕 초밥집), com.evolvegames.udangtangsushi, is operated by Evolve Games / Evolve Korea. Playing without an account is supported.

Delete directly in the game — from version 0.7.1

No email is needed. Open Settings → Privacy & account → Account & saved data → Delete cloud account & saves. Read the permanent-deletion confirmation, choose Verify & permanently delete, and verify with the same Google account linked to the game. Internet access is required.

This permanently deletes this game's Firebase authentication account and cloud progress, current puzzle, stars, decorations and regular-guest progress. It does not delete your Google account, other games' accounts, or local saves on this or other devices. It cannot be undone.

Cloud progress is removed before the authentication account. If completion cannot be verified, automatic backup pauses and the game offers a retry; it does not claim success. Retry with the same account if you see “Finish account deletion” or “Deletion needs confirmation”. A minimal marker containing the former game user identifier and deletion time remains to prevent stale devices from uploading erased saves again. It contains no gameplay progress, email or profile. Provider security logs may remain under their retention policies.

Delete local device data separately

Cloud and device saves are separate. Deleting one does not delete the other. Back up any progress you want to keep, close the game, then open Android Settings → Apps → Sushi Scramble → Storage → Clear data (sometimes “Clear storage”). The app name follows your device language. “Clear cache” alone does not erase progress.

This permanently clears all accounts' and guests' local saves, settings and login state on that phone. Cloud accounts and backups remain and may be restored when connected again. Delete local copies separately on other devices.

Sign-out and reconnection

Settings → Privacy & account → Disconnect Google is not deletion. Local copies and cloud saves remain. Connecting Google backup after account deletion may create a new game account and upload the local progress you kept.

If you cannot access the game

For an older version or an inaccessible app, contact evolvekorea@gmail.com from the linked email address and request “Sushi Scramble account deletion”. Email is a fallback, not required for normal in-app deletion. Never send a password or verification code.
