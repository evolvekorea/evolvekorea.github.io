로그인 계정 삭제 요청

게임에서 사용한 Google 계정의 이메일로 evolvekorea@gmail.com에 삭제 요청을 보내 주세요. 제목에 ‘우당탕 초밥집 계정 삭제 요청’을 적어 주시면 해당 게임의 Firebase 로그인 계정을 확인하여 삭제하고 결과를 안내합니다.

삭제 대상은 우당탕 초밥집의 Firebase 사용자 프로필과 로그인 연결 정보입니다. Google 계정 자체나 다른 게임의 계정은 삭제하지 않습니다. 비밀번호나 인증 코드를 보내지 마세요. 이미 생성된 서비스 보안 로그 등의 보유는 해당 제공업체 정책에 따를 수 있습니다.

기기 기록 삭제

Android 설정 → 애플리케이션 → 우당탕 초밥집 → 저장공간 → 데이터 삭제에서 이 기기의 스테이지 진행과 설정을 지울 수 있습니다. 이 작업은 되돌릴 수 없으며 서버의 Firebase 계정 삭제와는 별도입니다.

로그아웃만 하려면

게임 메인 화면의 설정 → Google 로그아웃을 선택하세요. 로그아웃은 계정 삭제가 아니며 이 기기의 게임 진행 기록은 유지됩니다.
