휴대폰에 남은 데이터 삭제

계정 삭제만으로 기기에 저장된 진행 상황·메모·오프라인 기록은 지워지지 않습니다. 휴대폰에서 설정 → 애플리케이션 → 포근포근 스도쿠 → 저장공간 → 데이터 삭제를 직접 진행해 주세요. 캐시 삭제만으로는 기록이 삭제되지 않습니다.

서버 기록도 삭제하려면 게임 안의 계정 삭제를 먼저 완료하세요. Google 미연결 게스트는 기기 데이터를 먼저 삭제하면 계정에 다시 접근할 수 없습니다.
