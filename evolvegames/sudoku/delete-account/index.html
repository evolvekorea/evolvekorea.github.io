계정 및 데이터 삭제

앱에서 직접 삭제하거나 이메일로 삭제를 요청하세요.

시행·최종 수정 · 2026년 9월 20일

포근포근 스도쿠 · Evolve Games의 계정과 데이터 삭제 안내입니다. 앱이 없어도 아래 이메일로 삭제를 요청할 수 있습니다. 이 절차는 다른 Evolve Games 게임이나 Google 계정 자체를 삭제하지 않습니다.

1. 앱에서 직접 삭제

  1. 게임의 설정 → 개인정보·광고·계정 삭제 → 계정 삭제를 선택합니다.
  2. 삭제할 계정으로 Google 재인증을 진행합니다.
  3. 안내를 확인하고 계정과 기록 삭제를 누릅니다.

진행 중인 대결은 기권 처리됩니다. 삭제된 계정과 기록은 복구할 수 없습니다. 계정 접근이 중단된 뒤 남은 기록을 순차적으로 정리합니다.

2. 앱 없이 이메일로 삭제 요청

  1. 게임에서 로그인한 Google 계정의 이메일로 evolvekorea@gmail.com에 메일을 보내 주세요.
  2. 제목에 포근포근 스도쿠 계정 삭제 요청, 본문에 게임 닉네임과 삭제할 범위를 적어 주세요. 전체 계정 또는 특정 정보의 삭제를 요청할 수 있습니다.
  3. 운영팀이 본인 확인 후 처리하며, 추가 확인이 필요한 경우와 완료 결과를 이메일로 안내합니다.
이전 이메일을 사용할 수 없으신가요?

접근할 수 없는 상황을 적어 문의해 주세요. 계정 소유권을 확인할 수 있는 최소한의 추가 절차를 안내합니다. 비밀번호·인증번호·신분증 사본은 보내지 마세요.

삭제 요청 메일 작성

아래 버튼은 메일 작성 화면을 엽니다. 내용을 확인하고 직접 전송해야 요청이 접수됩니다.

삭제 요청하기

메일 앱이 열리지 않으면 evolvekorea@gmail.com으로 직접 보내 주세요.

3. 삭제되는 정보와 남는 정보

  • 삭제: 스도쿠 인증 계정, 닉네임, 포인트, 순위 및 서버 개인 기록. 많은 기록은 나누어 정리합니다.
  • 익명화: 대결 상대에게 남는 경기 기록에서 계정 식별자를 제거하고 ‘삭제된 사용자’로 표시합니다.
  • 기기 기록: 계정 삭제만으로 오프라인 퍼즐·메모·기기 기록이 지워지지 않습니다. Android 설정 → 애플리케이션 → 포근포근 스도쿠 → 저장공간 → 데이터 삭제에서 제거할 수 있습니다. 메뉴명은 기기에 따라 다르며 복구할 수 없습니다.
  • 제공사 정보: Google 계정 자체는 유지됩니다. Firebase 인증·인프라 로그·백업, Unity 광고 정보 등에는 제공사별 보관·삭제 정책이 적용됩니다. Firebase 인증 정보는 삭제 요청 후 운영·백업 시스템에서 제거되기까지 최대 180일이 걸릴 수 있습니다.

구체적인 정보 처리 및 보관 내용은 개인정보처리방침에서 확인해 주세요.
