# TinyTable 운영정보

현재 앱 구현 기준: 기기 저장, Google 로그인 미연결, 모바일 광고 비활성화.
앱의 온라인 기능/광고를 활성화하기 전에 처리 정보와 앱 내 안내를 갱신할 것.

- https://evolvekorea.co.kr/evolvegames/tinytable/
- https://evolvekorea.co.kr/evolvegames/tinytable/privacy-policy/
- https://evolvekorea.co.kr/evolvegames/tinytable/delete-account/

기존 게임과 같은 정적 HTML/CSS 구조. 외부 폰트, JavaScript, 추적 스크립트 없음.
고객지원 이메일은 기존 Evolve Games의 evolvekorea@gmail.com 사용.
메일 링크는 사용자가 직접 보내며 자동 전송하지 않음.
현재 존재하지 않는 온라인 계정 삭제, 클라우드 복원, 고정 응답 기한을 약속하지 않음.

검토 근거: TinyTableRuntime.cs, ReleaseDiagnostics.cs, RewardedGoldAds.cs,
RewardedAds.json, UnityConnectSettings.asset, ProjectSettings.asset (2026-09-28).
