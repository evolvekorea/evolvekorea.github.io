TINYTABLE · 타이니테이블

데이터 삭제 안내

기기에 저장된 게임 진행과 문의 내역을 삭제하는 방법입니다.

시행·최종 수정 · 2026년 9월 28일

1. 기기 게임 데이터 삭제

  1. Android의 설정 → 애플리케이션 → TinyTable → 저장공간으로 이동합니다.
  2. 데이터 삭제를 선택하고 삭제 범위를 확인합니다. 메뉴 이름은 기기에 따라 다를 수 있습니다.
진행 상황과 같은 기기의 백업이 삭제됩니다.

가게 이름, 성급, 재화, 음식·재료, 직원·인테리어, 설정 등 기기 저장 전체가 삭제됩니다. 현재 클라우드 복원은 제공하지 않으므로 삭제 후 되돌릴 수 없습니다. 오류 문의 중이라면 먼저 운영팀의 안내를 확인해 주세요.

2. 온라인 계정 안내

현재 TinyTable에는 온라인 게임 계정이나 Google 로그인 연결이 없습니다. 삭제할 TinyTable 서버 계정도 없으며, 기기 데이터 삭제는 Google 계정 자체에 영향을 주지 않습니다.

3. 문의 내역 삭제 요청

기존 문의에 사용한 이메일로 evolvekorea@gmail.com에 ‘TinyTable 문의 내역 삭제 요청’이라는 제목과 삭제할 문의의 날짜·범위를 적어 보내 주세요. 운영팀이 필요한 확인 후 처리 결과를 회신합니다. 다른 이메일을 이용해야 한다면 상황을 적어 알려 주세요.
