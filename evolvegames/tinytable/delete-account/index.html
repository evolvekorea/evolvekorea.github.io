1. Tiny Table 계정·클라우드 데이터 삭제 요청

게임에 연결한 Google 계정의 이메일로 아래 주소에 ‘Tiny Table 계정 및 데이터 삭제 요청’을 보내 주세요. 해당 계정의 게임 저장도 함께 삭제할 것인지 명시해 주세요. 앱을 다시 설치하지 않고도 요청하실 수 있습니다.

계정·데이터 삭제 요청하기

evolvekorea@gmail.com · Evolve Games

메일 앱에서 내용을 확인한 뒤 직접 전송해 주세요. 비밀번호·인증번호·신분증은 보내지 마세요.

운영팀이 계정 소유 확인에 필요한 최소한의 확인을 진행한 뒤 Firebase 인증 계정과 연결된 게임 진행 데이터를 삭제하고 결과를 회신합니다. 처리에 추가 시간이 필요하거나 법령상 보존할 정보가 있으면 사유와 범위를 안내합니다. Google 계정 자체와 다른 게임의 기록은 삭제되지 않습니다. Tiny Table 계정을 삭제한 뒤 다시 Google 로그인하면 새로운 게임 계정이 생성될 수 있습니다.

게임 안에서도 설정 → Google 계정 · 저장 → 계정·데이터 삭제를 통해 이 안내를 열 수 있습니다. 클라우드 데이터만 삭제하거나 문의 내역을 삭제하고 싶으시면 원하는 범위를 적어 주세요.

2. 기기 게임 데이터 삭제

  1. 클라우드 계정을 함께 삭제할 경우 위 요청을 먼저 진행합니다. 자동 저장으로 다시 업로드되지 않도록 게임에서 로그아웃합니다.
  2. Android의 설정 → 애플리케이션 → Tiny Table → 저장공간 → 데이터 삭제를 선택합니다. 메뉴 이름은 기기에 따라 다를 수 있습니다.
기기 진행 상황과 같은 기기의 백업이 삭제됩니다.

기기 데이터 삭제만으로 클라우드 계정은 삭제되지 않습니다. 반대로 클라우드 계정 삭제만으로 현재 기기 저장이 삭제되지 않으므로 전체 삭제를 원하시면 두 절차를 모두 진행해 주세요.
