아래 이메일로 요청을 보내시면 운영팀이 본인 확인 후 처리하고 결과를 안내합니다. 즉시 자동 삭제 기능이 아닙니다.

1. 삭제 요청 보내기

  1. 게임 로그인에 사용한 Google 계정의 이메일 주소에서 evolvekorea@gmail.com으로 메일을 보내 주세요.
  2. 제목에 그만와라쫌 계정 삭제 요청을 적고, 본문에 게임 계정과 클라우드 저장 전체 삭제 또는 클라우드 저장만 삭제 중 원하는 범위를 적어 주세요.
  3. 운영팀이 해당 계정 소유 여부를 확인한 뒤 삭제를 진행하고 이메일로 처리 결과를 안내합니다. 요청한 계정 이메일을 이용할 수 없다면 먼저 지원팀에 문의해 주세요.

비밀번호, 인증번호, 신분증, 결제 카드 정보는 보내지 마세요. 다른 사람의 계정을 삭제하지 않도록 필요한 최소한의 본인 확인을 거칩니다.

2. 삭제되는 정보

  • 게임 계정 전체 삭제: 그만와라쫌의 Firebase 인증 계정(사용자 ID, 이름·이메일 등 프로필)과 연결된 클라우드 저장 데이터를 삭제합니다.
  • 클라우드 저장만 삭제: Firebase 인증 계정은 유지하고, 서버에 보관된 게임 진행·영웅·카드·재화·설정 등의 저장 기록을 삭제합니다.

삭제한 클라우드 진행은 복구할 수 없습니다. 계정을 삭제한 뒤 Google 로그인을 다시 하면 새로운 게임 계정이 만들어질 수 있고, 클라우드 저장을 다시 누르면 기기의 기록이 새로 업로드될 수 있습니다.

3. 삭제되지 않는 정보와 보관

  • Google 계정 자체는 삭제하지 않습니다. Gmail 등 다른 Google 서비스에는 영향을 주지 않습니다.
  • 휴대폰의 로컬 게임 기록은 원격으로 삭제하지 않습니다. 필요하면 Android 설정 → 앱 → 그만와라쫌 → 저장공간 → 데이터 삭제에서 별도로 삭제해 주세요. 먼저 필요한 기록을 확인하세요.
  • 삭제 요청 이메일은 요청 처리와 본인 확인에 필요한 기간 동안 보관한 뒤 삭제합니다. 법령상 보관이 필요한 정보가 있으면 해당 범위와 기간에 한해 보관합니다.
  • Google이 별도로 처리하는 광고·보안 기록은 Google의 보관 및 삭제 정책이 적용됩니다. 게임 계정 삭제만으로 Google의 모든 기록이 삭제되지는 않습니다.
