개인정보처리방침

게임 이용 중 처리되는 정보와 삭제 방법을 안내합니다.

시행일 · 2026년 10월 26일

Evolve Games(이볼브게임즈)는 그만와라쫌(com.stopcoming.defense)을 제공합니다. 개인정보 관련 문의와 권리 행사 연락처는 evolvekorea@gmail.com입니다. 이 방침은 현재 비공개 테스트 버전의 실제 기능을 기준으로 합니다.

1. 게임 저장과 선택적 Google 로그인

스테이지 진행, 영웅·카드 보유 및 장착 상태, 재화, 전투 이어하기 정보와 소리·그래픽 등의 설정을 이용자의 기기에 저장합니다. 로그인하지 않아도 게임을 이용할 수 있습니다.

Google 로그인을 선택하면 Firebase Authentication을 통해 게임 계정을 만들거나 연결합니다. Google 계정의 이름, 이메일 주소, 프로필 정보와 Firebase 사용자 ID, 인증에 필요한 토큰·IP 주소 등의 연결 정보를 계정 관리, 인증 및 보안 목적으로 처리합니다. Google 비밀번호를 게임이나 운영자에게 제공하지 않습니다. 인증 토큰은 Android/Firebase SDK에서 처리하며 게임 로그에 기록하지 않습니다.

로그인 후 이용자가 ‘클라우드 저장’을 누르면 진행·보유 아이템·재화·설정 등의 게임 저장 데이터와 저장 시각을 해당 사용자 ID에 연결하여 Cloud Firestore에 보관합니다. ‘복구’를 선택하면 저장된 진행을 불러올 수 있습니다. 로그인과 클라우드 저장은 선택 사항입니다. 이 기능은 기기 변경·재설치 시 기록 복구에 사용되며 광고 타겟팅에 사용하지 않습니다. 현재 실제 유료 결제는 연결되어 있지 않습니다.

Firebase는 Google이 제공하는 처리 서비스입니다. Firestore 데이터베이스는 서울 리전을 사용하지만 Firebase 인증·보안 처리는 Google의 해외 인프라를 포함할 수 있습니다. 전송은 암호화되며 클라우드 저장 접근은 해당 인증 계정으로 제한합니다. Firebase 개인정보 및 보안 안내

2. 보상형 광고와 Google 서비스

게임에는 Google AdMob(Google Mobile Ads SDK) 보상형 광고 기능이 포함되어 있으며, 현재 테스트 버전에서는 Google의 테스트 광고 단위를 사용합니다. 테스트 광고 사용을 개인정보 처리가 전혀 없다는 의미로 안내하지 않습니다.

광고 SDK는 광고 제공, 성과 측정, 오류 진단 및 부정 이용 방지를 위해 IP 주소와 이를 이용한 대략적 위치, 광고 식별자·앱 세트 ID 등의 식별자, 기기·앱 정보, 광고 표시·클릭·시청 등 상호작용과 진단 정보를 수집하고 Google에 공유할 수 있습니다. SDK의 전송 구간은 TLS로 암호화됩니다. 기기의 광고 ID 설정을 통해 광고 식별자를 재설정하거나 삭제할 수 있습니다.

광고 시청은 선택 사항입니다. SDK 초기화나 광고 요청 과정의 정보 처리는 시청 완료 여부와 다를 수 있습니다. 상세 사항은 Google 개인정보처리방침과 Google Mobile Ads 데이터 공개 안내를 확인해 주세요.

3. 고객지원 및 웹사이트

문의 이메일을 보내는 경우 이메일 주소, 문의 내용 및 직접 첨부한 자료를 문제 해결과 답변에 사용합니다. 문의 전송은 이용자의 선택이며 비밀번호·인증번호·신분증 등 불필요한 민감정보를 보내지 마세요.

문의 수신에는 Gmail, 이 페이지의 호스팅에는 GitHub Pages를 사용합니다. 호스팅 제공사는 IP 주소 등 접속 정보를 보안과 서비스 운영을 위해 처리할 수 있습니다. 이 페이지에는 별도의 분석·광고 추적 스크립트나 입력 폼을 설치하지 않았습니다. Google과 GitHub는 해외 인프라에서 정보를 처리할 수 있으며 각 서비스의 정책이 적용됩니다. GitHub 개인정보처리방침

4. 보관 및 계정·데이터 삭제

계정·클라우드 데이터 삭제 요청 안내 — 앱 설정의 ‘계정·데이터 삭제 요청’에서도 같은 페이지로 이동합니다. 앱을 삭제했거나 로그인할 수 없어도 이메일로 요청할 수 있습니다.

  • 게임 계정과 클라우드 기록은 이용 중 보관하며, 계정 소유자 확인 후 요청 범위에 따라 Firebase 인증 계정과 연결된 게임 저장 데이터를 삭제합니다. 클라우드 저장만 삭제하고 계정은 유지하는 요청도 가능합니다. 요청은 운영팀이 처리하며 즉시 자동 삭제가 아닙니다.
  • 기기 저장 정보는 서버와 별개입니다. Android 설정의 앱 저장공간에서 ‘데이터 삭제’를 실행하면 해당 기기의 게임 기록과 설정을 삭제할 수 있습니다. 클라우드 삭제만으로 로컬 기록이 지워지지는 않습니다.
  • 삭제된 클라우드 진행은 복구할 수 없습니다. 게임 계정 삭제는 Google 계정 자체를 삭제하지 않습니다. 이후 다시 로그인·저장하면 새 계정이나 클라우드 기록이 생성될 수 있습니다.
  • 문의·삭제 요청 정보는 처리 및 본인 확인에 필요한 기간 동안 보관한 뒤 삭제합니다. 법령에 따른 보관 의무가 있는 경우 필요한 범위와 기간에 한해 분리 보관합니다.
  • Google·GitHub가 별도로 처리하는 광고·보안·접속 기록에는 해당 제공사의 보관 및 삭제 정책이 적용됩니다. 기기 또는 게임 계정 삭제만으로 제공사의 모든 기록이 삭제되지는 않습니다.

5. 이용자의 권리와 보호

이용자 또는 적법한 대리인은 개인정보의 열람·정정·삭제·처리정지와 관련한 문의를 이메일로 요청할 수 있습니다. 요청 처리에 필요한 최소한의 본인 확인을 할 수 있습니다. 보호자도 자녀의 개인정보에 관해 문의할 수 있습니다.

문의 자료에 대한 접근은 필요한 담당자로 제한하며, 불필요한 개인정보 제공을 요구하지 않습니다. 게임은 연락처·카메라·마이크·정밀 위치 접근 권한을 요청하지 않습니다.

6. 변경 및 문의

정보 처리 방식이 바뀌면 이 페이지의 시행일과 내용을 갱신하고 필요한 경우 게임 내에서도 안내합니다.
