계정 및 데이터 삭제

앱에서 직접 삭제하거나, 앱을 다시 설치하지 않고
이메일로 삭제를 요청할 수 있습니다.

최종 수정 · 2026년 9월 15일

Evolve Games의 플래닛팝 게임 계정과 데이터 삭제 안내입니다. Google 계정 자체는 삭제되지 않습니다.

1. 앱에서 직접 삭제하기

  1. 삭제할 Google 계정으로 플래닛팝에 로그인합니다.
  2. 설정 → 계정 관리 → 게임 계정 삭제를 선택합니다.
  3. 삭제 내용을 확인하고 게임 계정 삭제 버튼을 누릅니다. 본인 확인을 위해 Google 로그인이 다시 필요할 수 있습니다.
  4. 삭제 완료 결과를 확인합니다. 오류가 표시되거나 진행할 수 없다면 아래 이메일로 요청해 주세요.

삭제된 온라인 기록은 복구할 수 없습니다. 로그아웃이나 앱 삭제만으로 온라인 기록이 삭제되지는 않습니다.

2. 이메일로 삭제 요청하기

  1. 게임에 로그인할 때 사용한 Google 계정의 이메일로 evolvekorea@gmail.com에 메일을 보내주세요.
  2. 제목은 “플래닛팝 계정 삭제 요청”으로 작성해 주세요.
  3. 본문에 게임 닉네임과 삭제 범위를 적어주세요. 계정 전체 또는 특정 정보만 삭제하도록 요청할 수 있습니다.
  4. 운영자가 본인 확인 후 처리 결과를 이메일로 안내합니다. 추가 확인이나 시간이 필요한 경우 회신으로 알려드립니다.
로그인할 수 없어도 요청할 수 있습니다.

사용하던 이메일에 접근할 수 없다면 상황을 적어 문의해 주세요. 비밀번호·인증번호·신분증 사본은 보내지 마세요.

삭제 요청 메일 작성

버튼은 메일 앱을 엽니다. 내용을 확인하고 직접 전송하시면 요청이 접수됩니다.

삭제 요청하기

메일 앱이 열리지 않으면 evolvekorea@gmail.com으로 직접 보내주세요.

3. 삭제되는 정보

  • Firebase Authentication에 등록된 플래닛팝 게임 계정
  • 온라인에 저장된 게임 닉네임
  • 온라인 최고 점수와 최고 행성, 발사·합체 수, 게임 식별자 및 갱신 시각 등 해당 계정의 순위 기록

문의 이메일 내역이나 아래의 삭제 보호 기록만 따로 삭제하고 싶은 경우, 삭제할 항목을 메일에 명시해 주세요.

4. 별도로 남는 정보

삭제 보호 기록: 이전 로그인 상태에서 삭제된 기록을 다시 올리지 못하도록 기존 사용자 식별자, 삭제 상태와 요청 시각을 별도로 보관합니다. 닉네임·이메일·점수는 포함하지 않습니다. 삭제 요청 후 7일이 지나고 게임 계정과 순위 삭제가 완료된 것을 확인하면 운영 점검 또는 추가 삭제 요청 처리 시 정리합니다. 인증 계정 삭제가 완료되지 않은 경우에는 완료 확인까지 유지합니다. 추가 삭제도 이메일로 요청할 수 있습니다.

기기 저장 데이터: 개인 기록, 진행 중인 게임, 에너지, 아이템과 설정은 기기에 남습니다. Android의 설정 → 애플리케이션 → 플래닛팝 → 저장공간 → 데이터 삭제에서 지울 수 있습니다. 메뉴 이름은 기기에 따라 다를 수 있습니다. 기기 데이터 삭제는 되돌릴 수 없습니다.

Google 계정 및 Google이 별도로 처리하는 정보: 게임 계정을 삭제해도 Google 계정은 유지됩니다. Google이 보관하는 광고 등 서비스 정보의 삭제는 Google 개인정보처리방침을 확인해 주세요.
