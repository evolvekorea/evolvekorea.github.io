우리동네 좀비 디펜스

계정 및 데이터 삭제

Google 로그인 계정과 클라우드 게임 데이터의 전체 또는 일부 삭제를 요청할 수 있습니다.

본 안내는 Evolve Games가 제공하는 모바일 게임 ‘우리동네 좀비 디펜스’의 계정 및 데이터 삭제 절차에 적용됩니다.

1. 삭제 요청 방법

  1. 게임에서 사용한 Google 로그인 이메일 계정으로 evolvekorea@gmail.com에 메일을 보내 주세요.
  2. 메일 제목을 “우리동네 좀비 디펜스 계정 삭제 요청”으로 작성해 주세요.
  3. 본문에 Google 로그인 이메일과 요청 범위(계정 전체 삭제 또는 일부 데이터 삭제)를 적어 주세요.
  4. 본인 확인 후 요청 접수 결과와 처리 완료 여부를 회신해 드립니다.

2. 삭제되는 데이터

  • Firebase Authentication에 연결된 게임 계정 정보
  • 스테이지 기록, 별과 재화, 출석 및 설정 정보
  • 타워·영웅 강화, 장비와 인벤토리 및 클라우드 저장 데이터

일부 데이터만 삭제하려는 경우 삭제할 항목을 메일에 구체적으로 적어 주세요.

3. 처리 기간 및 보관 예외

본인 확인이 완료된 삭제 요청은 원칙적으로 7일 이내 처리합니다. 관계 법령 준수, 결제 분쟁 처리 또는 부정 이용 방지에 필요한 최소 정보는 법령에서 정한 기간 동안 별도로 보관한 뒤 삭제할 수 있습니다.

익명화되어 특정 이용자와 연결할 수 없는 통계 정보와 제3자 서비스가 독립적으로 보관하는 정보에는 각 서비스 제공자의 정책이 적용될 수 있습니다.
